# Bika COA

**Certificates of Analysis (COA) add-on for Bika LIMS and SENAITE**

The `bika.coa` add-on provides a collection of professional, ISO 17025-compliant Certificate of Analysis templates for Bika Open Source LIMS.

It includes ready-to-use single-sample and multi-sample COA layouts that can be further customized by cloning.

### Features

- Single-sample and multi-sample COA layouts
- Batch reports with metadata consistency validation
- Hyperlinked Sample IDs, Batch IDs, and email addresses
- Support for Publication Specifications (with fallback to Analysis Specification)
- Accredited method indicators, uncertainty values, and verification details
- Verifier signature (instead of Publisher) – compliant with ISO 17025
- Professional elements: lab logo, accreditation seal, signatories, disclaimers, and optional watermark
- Clean "End of Report" marker and page numbering

### Installation

Install the `bika.coa` add-on in your Bika LIMS / SENAITE instance.

**Note:** This add-on requires **Impress** (Senaite add-on) for rendering the COAs.

### Configuration

1. Go to **Site Setup → Impress Settings**
2. Select the COA templates you want to use
3. Set your default template, page size, and orientation

For full documentation and usage instructions, visit:  
[Results Publication – COA](https://www.bikalims.org/new-manual/workflow/results-publication-coa/results-publication-coa)
